# WoodHouse — Premium Wooden Houses Platform (React.js)

A modern, high-performance E-commerce and catalog web application built with **React.js** for a premium wooden house manufacturing brand. The project features full detailing, high-quality component design, and smooth user interactions.

## 🚀 Features & Functionality

- **Dynamic Catalog:** House models and cards are rendered dynamically using structured **JSON data** storage.
- **Advanced Routing:** Implemented multi-page navigation (`Home`, `Contacts`, `Blog`, `Texnologia`, etc.) using **React Router**.
- **Custom Interactive Slider:** Built a fully custom, responsive media gallery/slider with thumbnails for detailed architectural views.
- **Lead Generation Forms:** Fully functional and stylized contact and estimation forms with input masks.
- **Pixel-Perfect UI:** High-fidelity detailing with responsive components, accurate hover states, and modern animations.

## 🛠️ Tech Stack

- **Frontend:** React.js (Functional Components, Hooks)
- **Routing:** React Router Dom
- **Data Management:** Local JSON databases
- **Styling:** Custom CSS (Flexbox, Grid, Advanced Hover Effects)
- **Version Control:** Git & GitHub
